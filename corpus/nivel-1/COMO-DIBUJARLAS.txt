Esto es lo que responde I1a, la unica pregunta que puede matar el proyecto:
?el rastreo es preciso sobre un trazo hecho a mano?

Los puntos ya estan elegidos y escritos. Tu no decides nada mientras dibujas:
solo marcas y unes. Eso es a proposito. La verdad se escribio ANTES que la
tinta, y por eso es exacta por construccion y no por medicion (D35).


-------------------------------------------------------------------------------
  LA HOJA, UNA SOLA VEZ
-------------------------------------------------------------------------------

Papel cuadriculado de 5 mm. La caja es de 20 cuadros de ancho por 16 de alto,
o sea 10 cm x 8 cm.

    fila 16  +---+---+---+---+ ... +---+     <- borde superior = ymax
             |   |   |   |   |     |   |
             +---+---+---+---+ ... +---+
             |   |   |   |   |     |   |
             ...                    ...
             |   |   |   |   |     |   |
    fila  0  +---+---+---+---+ ... +---+     <- borde inferior = ymin
             col 0                   col 20

    izquierda = xmin        derecha = xmax

LOS CUATRO BORDES SE TRAZAN CON PLUMA, siguiendo lineas de la cuadricula. El
extractor busca esa caja: es lo que ancla la escala. Sin recuadro completo no
hay de donde sacarla.

Las coordenadas de abajo son (columna, fila) contando cuadros desde la esquina
INFERIOR IZQUIERDA de la caja. La fila crece hacia arriba.


-------------------------------------------------------------------------------
  COMO SE DIBUJA CADA UNA
-------------------------------------------------------------------------------

  1. Traza la caja de 20 x 16 con pluma.
  2. Marca con lapiz un punto en cada interseccion de la lista.
  3. Unelos A MANO ALZADA con pluma, en el orden de la lista. Una curva suave,
     no segmentos rectos. Ahi esta la dificultad que se esta midiendo.
  4. Borra las marcas de lapiz si se ven.
  5. Fotografia.

NO escribas numeros en los ejes. La escala se teclea despues (D34): el
extractor no la lee, la recibe.


-------------------------------------------------------------------------------
  LA FOTO
-------------------------------------------------------------------------------

  - Lo mas perpendicular que puedas. Dos grados de inclinacion desplazan mas
    que toda la tolerancia del criterio; la rectificacion todavia no existe.
  - Luz pareja, sin sombra de tu mano ni brillo del papel.
  - Encuadra con margen: se recorta despues.
  - MISMAS CONDICIONES para las 24. Si cambias de telefono o de luz a media
    tanda, la escalera pierde el sentido, porque el nivel 0 ya midio la camara.

Guarda cada foto junto a su ficha, con el mismo nombre:

    corpus/nivel-1/C1-1.jpg   junto a   corpus/nivel-1/C1-1.verdad.json


-------------------------------------------------------------------------------
  LAS SEIS CONDICIONES
-------------------------------------------------------------------------------

Cuatro graficas por condicion. Estan a proposito, no al azar: dos de ellas son
donde D38 predice que el metodo falla, y medirlas es como se distingue "el
metodo no sirve" de "el metodo no sirve en verticales".

  C1  suave, sin rejilla trazada       el caso facil. Si aqui falla, se acabo
  C2  suave, CON rejilla trazada       repasa con pluma las lineas de la
                                       cuadricula cada 2 cuadros, antes de la
                                       curva. Aisla el borrado de rejilla
  C3  con tramo casi vertical          D38 predice falla parcial
  C4  que se dobla hacia atras         D38: sin arreglo con este metodo.
                                       NO CUENTA para el veredicto; se mide
                                       para conocer la frontera
  C5  trazo grueso o tembloroso        usa marcador grueso, o pulso suelto.
                                       Aisla el centroide de la tinta
  C6  rango asimetrico, con negativos  aisla la transformacion del paso 6

En C4 el orden de los puntos importa mas que en las otras: la curva se dobla y
pasa dos veces por la misma columna. Sigue la lista en orden.
